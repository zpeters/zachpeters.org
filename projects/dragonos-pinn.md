Worked with my buddy Bill Smith[^1] on a little project to get [DragonOS](https://sourceforge.net/projects/dragonos-pi64/) running on a raspberry pi using the [PINN](https://sourceforge.net/projects/pinn/) bootloader.  What this lets you do is multiboot multiple images on the same pi

See [the scripts and writeup here](https://codeberg.org/zpeters/DragonOS_PINN)

[^1]: [NY3L](https://www.qrz.com/db/NY3l) - _Stormbringer_
