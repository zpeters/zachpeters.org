Morse Code Glove (2016)

A glove that turns finger taps into Morse letters.

This is one of my experiments into eyes-free Oakley, I., Park, JS. (2007). Designing Eyes-Free Interaction. In: Oakley, I., Brewster, S. (eds) Haptic and Audio Interaction Design. HAID 2007. Lecture Notes in Computer Science, vol 4813. Springer, Berlin, Heidelberg. https://doi.org/10.1007/978-3-540-76702-2_13 interfaces. The original idea was for a car computer. That project never took off. The arrival of smart phones with pretty good voice assistants removed most of the need.

Nevertheless, I decided to see this one through. Please excuse my primitive construction skills!

The core of this project came together pretty quickly . Construction as you can see if very rough, but it was enough to get the basic concept going. Within a few minutes of its creation i could easily switch tracks and adjust the volume on my media player with little mental interruption of the task i was working on.

Future experimentation would be around the glove. As you can imagine it’s very cumbersome!

Hardware Interface

This just decodes finger touches (dit and dah) into letters just as if you had typed them into a keyboard. This makes it very simple to interface with other software. In my experimentation i created a simple script menu https://gist.github.com/zpeters/59a5f6345897309da9eef729780c09f3 to run different commands to control a music player.
