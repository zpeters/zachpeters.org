Ok - The Version Control Helper (2006-Current)

A small tool that finds changed git repos in my home folder, and the project I rewrite every few months to learn new languages.

For the longest time I have been using a small utility that i created sometime in the early 2000s. Truthfully, there isn't much to it. This application will look at all git projects in my home folder, if anything is changed it will list it. This alone solves a huge problem for me. I am forever jumping from project to project, so it's easy for me to forget to check something in. The other part of this is that with a quick command i can add, commit and push any matching repos. This is helpful for projects where I use git for more of a "backup" then a true version control system. For example, i use this for dotfiles I use gnu stow to manage my files. .

The meta project here is that I rewrite this app every few months. If I'm learning a new programming language I usually try it out here first. Off the top of my head this has been writting in: Go, Rust, Haskell, and Zig. Since I use this on Mac, Linux and Windows it's a good test for cross-platform compatibility as well.

Around 2025 I started using jj full-time. Support has been added to my ok tool
